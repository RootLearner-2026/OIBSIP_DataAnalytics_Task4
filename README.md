## Project Overview

This project focuses on cleaning and preprocessing a dataset using Python. Real-world datasets often contain missing values, duplicate records, and inconsistent data types. Data cleaning ensures that the dataset becomes accurate, reliable, and ready for further analysis or machine learning tasks.

The Airbnb NYC 2019 dataset was used in this project to demonstrate different data cleaning techniques using the Pandas library.

## Dataset

Dataset: **AB_NYC_2019**

The dataset contains information about Airbnb listings in New York City, including:

* Listing ID
* Host ID
* Listing name
* Location and neighborhood
* Price
* Number of reviews
* Availability

## Tools Used

* Python
* Google Colab
* Pandas
* NumPy

## Steps Performed

1. Data Loading
2. Dataset Exploration
3. Identifying Missing Values
4. Handling Missing Data
5. Removing Duplicate Records
6. Data Type Correction
7. Exporting Clean Dataset

## Results

The dataset was successfully cleaned by handling missing values, removing duplicates, and correcting data types. The cleaned dataset is now ready for further analysis and modeling.

## Conclusion

Data cleaning is a critical step in data analysis because it improves data quality and ensures more reliable insights. Proper preprocessing helps analysts make better decisions and build accurate models.
